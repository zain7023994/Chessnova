CHESSNOVA — ZAIN'S EDITION (UPGRADED WEB PROTOTYPE)

HOW TO OPEN ON ANDROID
1. Open Files / File Manager > Downloads.
2. Extract ChessNova-Pro-by-Zain.zip.
3. Open the ChessNova-Pro folder.
4. Tap index.html and choose Chrome.
5. Keep internet ON because chess.js is loaded from a CDN.

FEATURES
- Responsive fixed-square board designed for phone and desktop
- Vs Computer and local 2-player modes
- Three computer difficulty settings (lightweight minimax demo AI)
- Legal chess moves and standard rules supplied by chess.js
- Castling, en passant, promotion chooser, check/checkmate, stalemate and draw detection
- Move history, captured-piece display, undo, hint, board flip and restart
- Optional clocks (5 / 10 / 15 minutes)
- Optional move sound, FEN copy, PGN copy and PGN download
- Zain's Edition branding

IMPORTANT
This is an upgraded web prototype, not an APK and not yet a Play Store release.
The computer opponent is a lightweight browser-based AI, not Stockfish or a tournament-strength engine.
The chess rules library loads online, so the first launch needs an internet connection.
For a public release, test thoroughly on multiple phones, then package as an Android app and complete Google Play requirements.
